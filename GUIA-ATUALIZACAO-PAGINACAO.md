# NewPipe MOD 1.4.12 — miniaturas, páginas e instalação autónoma

O **NewPipe MOD** mostra a miniatura real de cada vídeo e divide as listas em páginas para manter o Kodi rápido e organizado.

## Como funcionam as páginas

- A configuração padrão apresenta **25 vídeos por página**.
- Quando houver mais resultados, o último item é uma seta grande **`>`** para abrir a próxima página.
- A página 2 mostra os vídeos 26–50; a página 3, os vídeos 51–75; e assim sucessivamente.
- A navegação preserva a pesquisa, categoria, canal, aba do canal e playlist selecionados.
- O item de próxima página é apenas navegação; não é um vídeo.

## Instalação no Kodi

1. Baixe o ZIP atual `plugin.video.newpipe-1.4.12-mod.zip`.
2. No Kodi, abra **Add-ons → Instalar a partir de ficheiro ZIP**.
3. Selecione o ZIP e aguarde a mensagem **Add-on instalado**.
4. Abra **Vídeos → Add-ons de vídeo → NewPipe MOD**.

> **Não é necessário instalar um repositório Kodi adicional nem módulos `script.module.*`.** Esta MOD é autónoma: as bibliotecas usadas pelo add-on já estão incluídas no próprio ZIP.

Se uma tela antiga ainda aparecer após atualizar, abra **Configurações do NewPipe MOD → Limpar cache**, saia do add-on e abra-o novamente.

## Quantidade por página

Em **Configurações do NewPipe MOD → Resultados por página**, deixe o valor em **25** para o comportamento acima. Pode escolher outro valor; ele será aplicado às próximas listas abertas.

## Verificação rápida

- Os cartões mostram miniaturas dos vídeos, não a fanart do add-on.
- Se houver mais de 25 resultados, o fim da lista mostra a seta **`>`**.
- Ao selecionar a seta, a lista abre a próxima faixa de vídeos sem repetir a escolha de tipo de busca.
