# NewPipe MOD para Kodi

> **Criador original / upstream:** [Twilight0](https://github.com/Twilight0/plugin.video.newpipe)  
> **MOD:** **@TrainAgain2**

Edição MOD do NewPipe para Kodi, preservando a autoria original, o repositório de origem e a licença GPL-3.0-only.

## Destaques desta MOD

- Reprodução direta do YouTube sem `plugin.video.youtube`, microG ou proxy local.
- Login de conta pelo fluxo de ativação YouTube TV compatível com SmartTube.
- Menus pessoais: subscrições, canais subscritos, ver mais tarde, playlists guardadas e histórico.
- Pesquisa de vídeos, canais, playlists e trailers; paginação de 25 itens.
- País, idioma, categorias e qualidade configuráveis.
- Fotos de perfis dos canais subscritos com cache local e recorte circular.
- Dependências necessárias incluídas no próprio ZIP.

## Instalação

1. Abra o [diretório de versões](../../releases) deste repositório quando houver uma versão publicada.
2. Transfira o ficheiro ZIP para o dispositivo Kodi.
3. No Kodi, use **Add-ons → Instalar a partir de ficheiro ZIP**.
4. Depois da instalação, abra **A minha conta do YouTube** e selecione **Sincronizar subscrições do YouTube** uma vez.
