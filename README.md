# NewPipe MOD para Kodi

> **Criador original / upstream:** [Twilight0](https://github.com/Twilight0/plugin.video.newpipe)  
> **MOD:** **@TrainAgain2**, **@angelitto2005**

Edição MOD do NewPipe para Kodi, preservando a autoria original, o repositório de origem e a licença GPL-3.0-only.

## Destaques desta MOD

- Reprodução direta do YouTube sem `plugin.video.youtube` ou proxy local.
- Login de conta pelo fluxo de ativação **YouTube TV** do NewPipe MOD.
- Menus pessoais: subscrições, canais subscritos, ver mais tarde, playlists guardadas e histórico.
- Pesquisa de vídeos, canais, playlists e trailers; paginação de 25 itens.
- País, idioma de conteúdo, idioma da interface, categorias e qualidade configuráveis.
- Interface completa nos idiomas português (PT/BR), inglês, espanhol, francês, alemão, italiano, neerlandês, romeno, turco, japonês e coreano.
- Fotos de perfis dos canais subscritos com cache local e recorte circular.
- Dependências necessárias incluídas no próprio ZIP.

## Instalação

1. Abra o [diretório de versões](../../releases) deste repositório quando houver uma versão publicada.
2. Transfira o ficheiro ZIP para o dispositivo Kodi.
3. No Kodi, use **Add-ons → Instalar a partir de ficheiro ZIP**.
4. Depois da instalação, abra **A minha conta do YouTube** e selecione **Sincronizar subscrições do YouTube** uma vez.

### Idioma da interface

Por padrão, a interface acompanha o **Idioma do conteúdo** e uma instalação nova começa em inglês. Em **Configurações → Geral → Idioma da interface**, é possível deixar o menu a seguir o idioma do conteúdo, fixá-lo num idioma específico ou usar o idioma global do Kodi. Para traduzir também a janela de definições do próprio Kodi, selecione o mesmo idioma em **Kodi → Configurações → Interface → Regional → Idioma**.

### Instalação autónoma

O ZIP da **NewPipe MOD** já contém as bibliotecas necessárias. **Não instale um repositório Kodi adicional, um kit anterior ou módulos `script.module.*` separados.**

Este repositório GitHub serve apenas para código-fonte e versões da MOD; não precisa de ser instalado no Kodi como repositório.
