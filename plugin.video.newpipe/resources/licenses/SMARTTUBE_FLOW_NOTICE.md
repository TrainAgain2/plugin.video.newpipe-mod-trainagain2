# SmartTube flow notice

The account-link user experience in NewPipe 1.1.0 follows the general TV device-code pattern visible in the public SmartTube project: show a short code on the TV, authorize it in a browser, and complete the connection in the background.

This add-on contains an independently written implementation based on Google's documented OAuth Device Authorization Flow. It does not include SmartTube authentication source files, SmartTube OAuth client IDs, client secrets, cookies, tokens, or any microG component.

Reference: https://github.com/yuliskov/SmartTube
